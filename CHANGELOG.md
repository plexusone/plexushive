## [v0.1.0] - 2026-11-19

### Highlights

- Roles, decisions and a message envelope as JSON for coordinating long-lived coding agents, with Go types as the source of truth
- Repository stewardship: several roles may work in a repository, at most one stewards it, and organization patterns are supported
- `plexushive` CLI to validate a hive directory, list the roles working in a repository and print the JSON Schemas

### Added

- `Role` format with status, mission, autonomy (`observe`, `prepare`, `execute`), repository affinities, initiatives and peers ([`6d74225`](https://github.com/plexusone/plexushive/commit/6d74225))
- `Decision` format for an append-only decision log, with alternatives and supersede links validated in both directions ([`6d74225`](https://github.com/plexusone/plexushive/commit/6d74225))
- Message `Envelope` with `Format` and `Parse` for `question`, `request`, `status` and `decision-needed` messages ([`6d74225`](https://github.com/plexusone/plexushive/commit/6d74225))
- `RolesFor` and `Steward` resolve the roles that work in a repository, steward first ([`6d74225`](https://github.com/plexusone/plexushive/commit/6d74225))
- `Load` reads a hive directory strictly, and `Hive.Validate` checks roles and decisions together ([`3ad0eda`](https://github.com/plexusone/plexushive/commit/3ad0eda))
- JSON Schemas for roles and decisions generated from the Go types ([`3ad0eda`](https://github.com/plexusone/plexushive/commit/3ad0eda))
- `plexushive validate`, `roles` and `schema` commands ([`2bdc377`](https://github.com/plexusone/plexushive/commit/2bdc377))
