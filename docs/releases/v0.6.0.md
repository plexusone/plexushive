# Release Notes - v0.6.0

**Release Date:** 2026-11-22

## Overview

A decision request lasts only as long as a report carries it, and the open
questions in a design record, such as an ADR's "Open questions" section,
are in no report at all. This release adds **open items**: one list in the
hive of every question waiting on the operator, wherever it was raised,
kept until it is decided or withdrawn.

## New Features

### Open items

`open-items.json` in the hive directory lists each question with its key
(`<identity>/<request id>`), its source (a report, an ADR or another
document), a status and the decision request:

| Status | Meaning |
|---|---|
| `draft` | A question with no options yet, such as one copied from an ADR |
| `open` | A complete decision request waiting on the operator |
| `deferred` | Waits on something its note names |
| `decided` | Answered by the decision it names |
| `withdrawn` | Dropped by its work identity without a decision |

`hive.Load` reads the file and `Hive.Validate` checks it against the work
identities and the decision log. A hive without the file has no open
items.

### Commands

```bash
plexushive -C my-hive open                  # open, draft and deferred items, by status and work identity
plexushive -C my-hive open website --all    # one work identity's items, closed ones too
plexushive -C my-hive open sync             # update the list from the reports and the decision log
plexushive schema open-items
```

`open sync` adds requests not yet listed, opens a draft once its work
identity asks a request with the same ID (this is how an ADR question gets
its options), marks items answered by a decision as decided, and withdraws
a report's question its work identity dropped without a decision. A work
identity without a readable report is left as it is. `decide` marks the
item it answers as decided.

## Library

- `hive.OpenItems`, `hive.OpenItem`, `hive.ItemSource`, `hive.ItemStatus`
  and `hive.SourceKind`, with their constants and `hive.ItemStatuses`
- `hive.LoadOpenItems`, `hive.WriteOpenItems`, `hive.ValidateOpenItems`,
  `hive.OpenItemsSchema` and `hive.OpenItemsFile`
- `(*OpenItems).Sync`, returning a `SyncResult`; `(*OpenItems).MarkDecided`
  and `(*OpenItems).Item`
- `Hive.Open`
