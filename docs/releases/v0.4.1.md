# Release Notes - v0.4.1

**Release Date:** 2026-11-21

## Fixed

- `report submit` rejected a pull request given as `#<n>` even when the
  item or action named exactly one repository, because it validated the
  report before expanding the short form. It now expands first, and
  validation accepts `#<n>` wherever one repository is named.

## Changed

- Action IDs may contain dots, so an ID can carry a version, such as
  `deploy-v0.3.0`.

## Documentation

- An item's `versions` use `v1.2.0` when it names one repository, and
  `<module>@<version>` when it spans several.

## Installation

```bash
go install github.com/plexusone/plexushive/cmd/plexushive@v0.4.1
```
